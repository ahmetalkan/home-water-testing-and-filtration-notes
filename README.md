# Home Water Testing and Filtration Notes

A homeowner reference for testing municipal or private well water before buying equipment, interpreting hardness measurements, and matching activated carbon, ion-exchange softeners, and reverse osmosis to real lab results, citing US EPA, USGS, and MedlinePlus.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — test-before-treating home water workflow: `https://ahmetalkan.github.io/home-water-testing-and-filtration-notes/`
- Subpage — testing protocols for municipal supplies vs private wells: `https://ahmetalkan.github.io/home-water-testing-and-filtration-notes/well-vs-municipal-water-tests.html`
- Subpage — understanding water hardness and ion-exchange softeners: `https://ahmetalkan.github.io/home-water-testing-and-filtration-notes/water-hardness-and-softeners.html`
- Subpage — comparing activated carbon filtration and reverse osmosis: `https://ahmetalkan.github.io/home-water-testing-and-filtration-notes/carbon-vs-reverse-osmosis.html`

It cites public pages on [watertreatmentpro.com](https://watertreatmentpro.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
